The repertoire

A list that shows its sources

The repertoire is Worldline's list of journalists, editors and producers, sorted by beat. Each entry says where the name came from and how it was checked.

A repertoire entry is a short file. It holds the person's name, the outlet, the beats the person covers in their own words, the public pages that show those beats, the language and region of coverage and the way the person has asked to be approached. Nothing in the entry is written from memory. Each line carries its source, the method that found it, the agent or person who read it and the time it was read.

Public sources are the only source for a new contact. These include bylines, beat pages, outlet masthead pages, newsletters that are open to read and public speaker lists. Worldline does not buy contact lists, does not scrape private groups and does not take a contact from a source that forbids it.

When a new name is found, the executive agent opens a thread for that contact. The thread checks the beat, confirms that the person still covers it, and writes the entry. The desk reads each new entry before it is used in a pitch plan. A name with no confirmed beat is kept as unplaced and is not pitched.

The repertoire grows slowly on purpose. A small list that is right is worth more to a customer than a large list that is guessed.

How a beat is searched

  1. Name the beat

    A customer names the beats it wants to reach. A beat is a topic, a region and a language, for example renewable grid storage in Germany, written in German.

  2. Search the entries

    The repertoire is searched by beat, region, language and outlet. The search returns the entries that match and the sources behind each match.

  3. Check the open list

    Only open entries are pitched. Closed entries are never pitched again. Unplaced entries wait until a beat is confirmed.

  4. Plan the pitch

    The desk writes a pitch plan from the open entries. The plan says why each person was chosen, from which source.

Limits

  • The repertoire does not promise that any listed journalist will cover a customer.
  • A listed journalist has not agreed to receive anything from Worldline unless they have said so.
  • Sending pitches to journalists is not switched on yet. Entries are built and checked now.
